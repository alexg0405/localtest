# 1. Two Sum

Easy · Array · Hash map · [Official statement on LeetCode](https://leetcode.com/problems/two-sum/)

Given a list of integers `nums` and an integer `target`, return the
indices of the two different elements that add up to `target`, smaller index
first. Every input has exactly one answer, and you can't use the same element
twice.

```python
two_sum([4, 9, 1, 7], 8)    # [2, 3]   because 1 + 7 == 8
two_sum([5, 5, 2], 10)      # [0, 1]
```

Write `two_sum(nums, target)` in `solution.py` (open in the editor).
