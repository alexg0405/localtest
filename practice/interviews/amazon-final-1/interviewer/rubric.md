# Scoring rubric: Amazon SDE intern final round 1

Score each area 1–5, or "not observed" when there is no evidence. This is a
no-AI round.

| Area | 1 | 3 | 5 |
|---|---|---|---|
| Problem understanding | Codes immediately. | Asks about ties or duplicates. | Clarifies ties, duplicates, k bounds, on-time equality, and input size. |
| Leadership Principles | Vague, "we", no result. | STAR with some specifics. | Specific, personal actions, measurable result, reflection, and strong follow-up answers. |
| Problem solving and complexity | No approach stated. | Working approach and time complexity. | Heap or sort tradeoff, time and space complexity, and an efficient design for the follow-up. |
| Correctness and edge cases | Example fails. | Example and most edge cases pass. | All edge cases, the follow-up, and performance. |
| Testing and dry run | No dry run. | Dry-runs the example. | Dry-runs edge cases and names the tests they'd write. |
| Code quality | Hard to follow. | Clear. | Small, well-named helpers; no duplication between the batch and tracker code. |
| Communication | Silent coding. | Explains when asked. | Narrates continuously, checks in with the interviewer, and asks good questions at the end. |
