# 49. Group Anagrams

Medium · Hash map · String · Sorting · [Official statement on LeetCode](https://leetcode.com/problems/group-anagrams/)

Given a list of lowercase words, group together the words that are
anagrams of each other (the same letters in a different order). Return a list
of groups; the order of the groups and of the words inside each group doesn't
matter.

```python
group_anagrams(["stop", "pots", "cat", "tops", "act", "dog"])
# [["stop", "pots", "tops"], ["cat", "act"], ["dog"]]   (in any order)
```

Write `group_anagrams(words)` in `solution.py` (open in the editor).
