# 767. Reorganize String

Medium · String · Heap · Greedy · Counting · [Official statement on LeetCode](https://leetcode.com/problems/reorganize-string/)

Rearrange the characters of `s` so that no two equal characters are next to
each other. Return any arrangement that works, or `""` if none exists.

```python
reorganize_string("aabc")   # for example "abac" or "acab"
reorganize_string("aaab")   # ""
```

Write `reorganize_string(s)` in `solution.py` (open in the editor).
