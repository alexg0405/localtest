# 3. Longest Substring Without Repeating Characters

Medium · String · Sliding window · Hash map · [Official statement on LeetCode](https://leetcode.com/problems/longest-substring-without-repeating-characters/)

Given a string `s`, return the length of the longest contiguous stretch of
characters in which no character appears more than once.

```python
length_of_longest_substring("abcbdea")   # 5   ("cbdea")
length_of_longest_substring("zzzz")      # 1
length_of_longest_substring("")          # 0
```

Write `length_of_longest_substring(s)` in `solution.py` (open in the editor).
