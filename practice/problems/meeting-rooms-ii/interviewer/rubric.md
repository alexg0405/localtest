# Scoring rubric: practice problem

Score each area 1–5, or "not observed" when there is no evidence. Hints are
noted. In real mode they lower the problem-solving score, as relying on an
interviewer's hints would; in coach mode they don't.

| Area | 1 | 3 | 5 |
|---|---|---|---|
| Problem understanding | Codes immediately. | Asks about one or two constraints. | Clarifies input size, edge cases, and output format before coding. |
| Problem solving and complexity | No approach stated. | A working approach and its time complexity. | Brute force first, then the optimal approach, with time and space complexity and the tradeoff. |
| Correctness and edge cases | The examples fail. | The examples and most edge cases pass. | Every hidden test, including performance. |
| Testing and verification | Never runs or traces the code. | Runs the examples. | Dry-runs by hand, runs custom inputs for edge cases, and fixes what they find. |
| Code quality | Hard to follow. | Clear. | Idiomatic, well named, no dead code. |
| Communication | Silent. | Explains when asked. | Narrates throughout and states the complexity unprompted. |
