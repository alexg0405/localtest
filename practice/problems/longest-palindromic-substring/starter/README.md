# 5. Longest Palindromic Substring

Medium · String · Expand around center · Dynamic programming · [Official statement on LeetCode](https://leetcode.com/problems/longest-palindromic-substring/)

Given a non-empty string `s`, return its longest contiguous substring that
reads the same forwards and backwards. If several are equally long, return any
one of them.

```python
longest_palindrome("racecars")   # "racecar"
longest_palindrome("abcd")       # any single character, like "a"
longest_palindrome("xabbay")     # "abba"
```

Write `longest_palindrome(s)` in `solution.py` (open in the editor).
