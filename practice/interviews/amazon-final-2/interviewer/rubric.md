# Scoring rubric: Amazon SDE intern final round 2

Score each area 1–5, or "not observed" when there is no evidence. This is a
no-AI round.

| Area | 1 | 3 | 5 |
|---|---|---|---|
| Problem understanding | Codes immediately. | Asks about moves or unreachable cases. | Clarifies moves, several stations, unreachable, no dock, and grid size. |
| Leadership Principles | Vague, "we", no result. | STAR with some specifics. | Specific, personal actions, measurable result, reflection, and strong follow-up answers. |
| Problem solving and complexity | No approach stated. | BFS with its time complexity. | Explains BFS versus DFS, time and space, and the (row, col, clears) state for the follow-up. |
| Correctness and edge cases | Example fails. | Example and most edge cases pass. | All edge cases, the follow-up, and performance. |
| Testing and dry run | No dry run. | Dry-runs the example. | Dry-runs edge cases (no path, several stations) and names the tests. |
| Code quality | Hard to follow. | Clear. | A neighbors helper, a single visited structure, no duplication. |
| Communication | Silent coding. | Explains when asked. | Narrates continuously and asks good questions at the end. |
