# Scoring rubric: Amazon SDE intern coding round

Score each area 1–5, or "not observed" when there is no evidence. This is a
no-AI round. Hints lower the problem-solving score; a candidate who needed the
interviewer's push to optimize but got there scores below one who found it
alone, and above one who never did.

| Area | 1 | 3 | 5 |
|---|---|---|---|
| Problem understanding | Codes immediately. | Asks about equal prices or input size. | Clarifies strictly lower, never cheaper, input size, and empty input. |
| Problem solving and complexity | No approach stated. | Brute force with its complexity, then the stack after being pushed or hinted. | Brute force and its cost, then the O(n) stack without hints, with a clear argument for why it's O(n). |
| Correctness and edge cases | Example fails. | Example and most edge cases pass. | All edge cases, the follow-up, and the large inputs. |
| Testing and dry run | No dry run. | Dry-runs the example. | Dry-runs equal prices, rising prices, and one big drop, and names the tests. |
| Code quality | Hard to follow. | Clear. | Short, clear names (waiting days, waits), no duplication between the batch and streaming versions. |
| Communication | Silent coding. | Explains when asked. | Narrates continuously, answers the interviewer's questions directly, and asks good questions at the end. |
